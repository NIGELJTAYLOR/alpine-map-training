### Exercise 1 — Legend lookup
This depends on the learner's map. Check that each requested feature has been found in the legend, and that the learner's description (or sketch) clearly identifies the printed symbol. A short verbal description ("a small black square", "a dashed black line", "a row of blue tufts") is acceptable as long as it picks out the distinguishing visual features.

### Exercise 2 — Symbol hunt on the map
Answers vary. The important check is whether the learner has found real examples of:

- a building or hut,
- a path or route,
- a water feature,
- a vegetation feature,
- and a steep or rocky feature.

### Exercise 3 — What does this tell you?
Model answers:

1. A bridge symbol crossing a blue line suggests there is a crossing point over a stream or river.
2. A hut near a path junction is useful because it is often a distinct feature that can help confirm position.
3. Cliff or steep-ground symbols should make the learner think carefully about safety, route choice and whether the line is practical.

### Exercise 4 — Tiny map-square description
A strong answer identifies four specific features the learner can see in their chosen 2 cm × 2 cm square, with each feature justified from a colour or symbol on the map. The four features should ideally span different categories rather than four of the same kind, for example:

- a vegetation or land-cover feature (open land, woodland);
- a water or drainage feature (stream, lake);
- a built feature (building, hut, bridge);
- and a terrain or steep-ground clue (contour shape, cliff symbol, rocky ground).

Accept any four well-justified features; the test is that each one is anchored in something visible on the map, not just guessed.
